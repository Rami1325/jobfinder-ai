# frontend/src

Every page, component, hook, store and lib file under this directory belongs to a department with a handbook file in `docs/handbook/` (path from the repo root). Before the first edit, find the file in the third column of the index table in the root `CLAUDE.md` (*Key invariants*) and read that handbook file in full. `npm run build` runs `scripts/check-mirrors.js` first; what each of its checks pins is in `docs/handbook/testing.md`.

This file is a pointer and must stay one: a rule has one home, in its department's handbook file, never here.
