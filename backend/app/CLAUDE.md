# backend/app

Every module under this directory belongs to a department with a handbook file in `docs/handbook/` (path from the repo root). Before the first edit, find the module in the third column of the index table in the root `CLAUDE.md` (*Key invariants*) and read that handbook file in full. After any backend change, run the offline smoke test (root `CLAUDE.md`, *Testing*).

This file is a pointer and must stay one: a rule has one home, in its department's handbook file, never here.
